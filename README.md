## Tech Stack

`HTML5` · `CSS3` · `Vanilla JS` · `GitHub Actions` · `GitHub Pages`

## Features

- 🌗 Dark / Light theme — respects system preference, persisted via `localStorage`
- 📱 Fully responsive & accessible (ARIA, keyboard navigation, skip-to-content)
- 🔍 SEO optimised — Open Graph, Twitter Card, JSON-LD, `sitemap.xml`
- 📦 PWA ready — `manifest.json` + multi-resolution icons
- ⚡ Zero dependencies, zero trackers
- 🚀 Auto-deployed via GitHub Actions on every push to `master`

## Project Structure

```
portfolio/
├── .github/workflows/static.yml    # CI/CD pipeline
├── index.html                     # Main page
├── 404.html                       # Custom error page
├── manifest.json                  # PWA manifest
├── sitemap.xml / robots.txt       # SEO
├── Saroj_Resume.pdf               # Downloadable resume
└── assets/
    ├── css/                       # Stylesheets
    ├── js/                        # Scripts (theme-init, main)
    └── icons/                     # PWA & favicon icons
```

## Run Locally

```bash
git clone https://github.com/saroj789/portfolio.git
cd portfolio
npx serve .
# Visit http://localhost:3000
```

## Deployment

Deployed automatically via **GitHub Actions** (`static.yml`) on every push to `master`.

```bash
git add .
git commit -m "feat: your change"
git push origin master
```

> Manual trigger also available under **Actions → Deploy static content to Pages → Run workflow**.
